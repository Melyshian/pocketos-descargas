# 📥 Descargas de PocketOS

**PocketOS — Your everyday toolkit.**

Aquí encontrarás los APKs oficiales de PocketOS para Android: la versión más
reciente siempre está en la última *release* de este repositorio. 👇

## 📲 Cómo instalar

1. Descarga el archivo `.apk` de la última versión (sección **Releases**,
   a la derecha en GitHub o abajo en móvil).
2. En tu Android, abre el archivo descargado y permite "instalar apps
   desconocidas" si el sistema lo pide.
3. ¡Listo! Abre PocketOS y empieza a usarla. 💖

> ⚠️ Descarga siempre desde aquí o desde nuestro Discord oficial para evitar
> copias modificadas.
